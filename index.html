Step-by-Step Incident Workflow
  1. Isolate affected user workstation from network segment.
  2. Revoke active OAuth & M365 session tokens via Azure AD / IAM console.
  3. Inspect mail transfer logs (MTA) for outbound beaconing or secondary link distribution.
  4. Force password reset & require FIDO2/MFA re-enrollment.
